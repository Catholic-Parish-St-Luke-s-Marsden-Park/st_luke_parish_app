## Implementation

### Core
- **`lib/core/config/backend_uri.dart`:** `validateBackendUri(raw, isRelease:, envKey:)`, extracted from `NotificationService.resolveBackendUri`. That method now delegates to it, and its existing tests are unchanged and pass.
- **`lib/core/config/api_base_uri_provider.dart`:** `resolveApiBaseUri()` (pure) and `apiBaseUriProvider` (keepAlive, reads dotenv).
  - Uses `API_BASE_URL` (origin only) or, when it's unset or blank, the origin of `BASE_URL`.
  - A set but invalid value returns null.
  - Only http(s) is accepted, and only https in release builds.
- **`assets/app.env`:** `API_BASE_URL=https://parish-app-service.fly.dev`.

### Ministries domain
- **`entities/ministry.dart`:** `emoji` dropped, and `ctaEmail` replaced by `contactEmail` and `emailSubject`. `contactMailtoUri` builds the issue's encoded `Uri(scheme: 'mailto', …)`.
- **`entities/ministry_category.dart`:** new.
- **`failures/ministries_failure.dart`:** sealed, with NotConfigured, Network, Parsing and MinistryNotFound.
- **`repositories/ministries_repository.dart`:** `watchMinistries()` stream, `refreshMinistries()` and `getMinistryById()`.

### Ministries data
- **`parsers/ministries_json_parser.dart`:**
  - Parses the list and single-ministry bodies with strict type checks.
  - Every failure names the field's path, and unknown fields are ignored.
- **`datasources/ministries_remote_datasource.dart`:**
  - 10s timeout, `Accept` and User-Agent headers, UTF-8 decoded from the raw bytes.
  - An injectable `RequestHeadersBuilder` for App Check.
  - A 404 on the detail call becomes not-found, and a null base becomes not-configured.
- **`datasources/bundled_ministries_source.dart`:** loads `assets/ministries_fallback.json` through an `AssetBundle`.
- **`cache/ministries_cache.dart`:** the `MinistriesCache` interface and `SharedPreferencesMinistriesCache`, which stores the raw body under `ministries_cache_v1`.
- **`repositories/ministries_repository_impl.dart`:** stale-while-revalidate.
  - The cache is emitted first, then the network result, which is also saved.
  - On a failure the cache stands, or the bundled copy is used when there is no cache.
  - The bundled copy is never saved. A corrupt or unreadable cache counts as a miss, and cache writes are best-effort.
- **`assets/ministries_fallback.json`:** a snapshot of the live `GET /v1/ministries` taken on 2026-10-08 and registered in `pubspec.yaml`.
- **`data/config/static_ministries_config.dart`:** deleted.

### Ministries presentation
- **`providers/ministries_providers.dart`** (generated):
  - `ministriesRepositoryProvider` (async, SharedPreferences).
  - A `Ministries` StreamNotifier with `refresh()` → bool.
  - `ministryByIdProvider(id)`: looks in the list first, then fetches by id.
- **`screens/ministries_screen.dart`:**
  - A `ConsumerWidget` with a `RefreshIndicator` and `AlwaysScrollableScrollPhysics`.
  - Loading, error+retry, empty and data states sit below the hero, and categories render in API order.
  - A failed refresh shows a SnackBar, and previous data stays during a reload.
- **`screens/ministry_detail_screen.dart`:**
  - A `ConsumerWidget` on `ministryByIdProvider`, with loading, not-found ("Ministry not found."), error+retry and data states.
  - The CTA launches `contactMailtoUri`.
- **`widgets/ministries_status_view.dart`:** loading and message+retry views, using `TextTheme` styles and a 48x48 retry target.

### Docs and config
- **`CLAUDE.md`:** allows the parish API's `GET /v1/*` (plus the existing `POST /tokens`) and forbids `/admin`.
- **README:** a "Parish API (Ministries)" section covering `API_BASE_URL` and the fallback-refresh command.
- **`test/release_readiness_test.dart`:** an opt-in `API_BASE_URL` https check.
- **ADR:** `.claude/decisions/0006-ministries-from-parish-api.md`.
