4. `test/app/shell/app_bar_chrome_test.dart` — "REQ-F02-019: AppBar/pills render identically across all 6 tabs" — fails with `A platform implementation for 'webview_flutter' has not been set` when the test cycles to the Donate tab and `SimpleWebViewScreen` constructs a `WebViewController`. This is a well-known `webview_flutter` widget-testing requirement (a fake `WebViewPlatform.instance` must be registered in test `setUp`/`setUpAll` before any widget test builds a `WebViewController`) — not a functional/production bug; the real app registers its platform implementation automatically via plugin registration. Tester will need to register a fake `WebViewPlatform` before any test that builds `AppShell` (all 6 tabs), `DonateScreen`, or `SimpleWebViewScreen` directly.

No other tests were affected; `flutter analyze` and `dart format . --set-exit-if-changed` are both clean.
