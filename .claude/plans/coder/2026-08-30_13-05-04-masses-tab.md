## Summary of Implementation
Replaced the Masses tab's `PlaceholderScreen` stub with a real, static Mass-schedule screen, per all 24 approved requirements (REQ-F04-001..024).

### Domain
- `lib/features/masses/domain/entities/mass_time.dart` — typed, immutable `MassTime` entity (const constructor: `time` String, `name` String, `note` String?).
- `lib/features/masses/domain/entities/mass_sub_group.dart` — `MassSubGroup{label, rows}`, groups a labeled set of `MassTime` rows (used for the "What's On" card's three sub-groups).
- `lib/features/masses/domain/entities/mass_schedule.dart` — `MassSchedule{whatsOnSubGroups, reconciliationAndSacraments}`, the full typed content shape exposed to the UI.

### Data
- `lib/features/masses/data/config/static_mass_schedule_config.dart` — static `const List<MassTime>` values for `sundayMasses`, `saturdayVigilMasses`, `weekdayMasses`, and `reconciliationAndSacramentsRows`, containing exactly the rows specified in the BA plan's Acceptance Criteria (REQ-F04-005..009); combined into `whatsOnSubGroups` (3 sub-groups, in order) and the top-level `staticMassSchedule` constant. No repository/datasource/scraper/parser exists for this feature (REQ-F04-018) — content is static config, not fetched.

### Presentation
- `lib/features/masses/presentation/providers/mass_schedule_provider.dart` (+ generated `.g.dart`) — a `@riverpod` functional provider (`massScheduleProvider`) exposing `staticMassSchedule` to the screen. `MassesScreen` reads this provider (`ConsumerWidget` + `ref.watch`) rather than importing the static config directly (REQ-F04-017).
- `lib/features/masses/presentation/screens/masses_screen.dart` — replaces the `PlaceholderScreen` stub; composes `MassesHeroBanner` + `WhatsOnSection` + `ReconciliationAndSacramentsSection`. No business logic in the widget tree (REQ-F04-019).
- `lib/features/masses/presentation/widgets/masses_hero_banner.dart` — eyebrow "ST LUKE'S · MARSDEN PARK" + title "Mass Times", no address/subtitle line (REQ-F04-002).
- `lib/features/masses/presentation/widgets/mass_section_header.dart` — top-level section title widget ("What's On" / "Reconciliation & Sacraments"), kept local to the Masses feature rather than reusing Parish's `SectionLabel`, matching the precedent Ministries set with its own `MinistryCategoryHeader` (feature-concern isolation per `CLAUDE.md`).
- `lib/features/masses/presentation/widgets/mass_sub_group_label.dart` — smaller, distinctly-styled sub-group label ("Sunday" / "Saturday Vigil" / "Weekday"), visually distinguishable from `MassSectionHeader`'s top-level titles per the BA plan's Unknowns/assumption note.
- `lib/features/masses/presentation/widgets/mass_card.dart` — rounded card container, reused for both sections.
- `lib/features/masses/presentation/widgets/mass_row.dart` — plain-text row rendering `time` + `name` + optional `note`; no icon, no tap affordance (REQ-F04-011, REQ-F04-012). Uses `Wrap` (not a fixed-width Row/column split) for the time+name pair so long non-clock-time strings ("By enrolment") and increased system text scale reflow instead of overflowing (REQ-F04-020).
- `lib/features/masses/presentation/widgets/whats_on_section.dart` — Section 1: one `MassCard` containing the three ordered sub-groups (REQ-F04-003..008).
- `lib/features/masses/presentation/widgets/reconciliation_and_sacraments_section.dart` — Section 2: one `MassCard` containing the 3 flat rows in order (REQ-F04-009, REQ-F04-010).

- "What's On": Sunday (3 rows, no notes), Saturday Vigil (1 row, note "Reconciliation from 4:30–5:25pm"), Weekday (3 rows, no notes) — exact copy from the BA plan (REQ-F04-005..008).
- "Reconciliation & Sacraments": Reconciliation (note "Before the Vigil Mass"), Baptisms & House Blessings, Sacramental Programme — exact copy (REQ-F04-009, REQ-F04-010).
- No icon/emoji/glyph anywhere on this screen (REQ-F04-011); no "Details"/chevron/tap affordance on any row (REQ-F04-012); every `time` value is weekday+time or one of the two exact non-clock-time strings, never a date/month (REQ-F04-013); exactly 2 sections and 2 cards total (REQ-F04-014).
- Section titles, sub-group labels, and row text use named `TextTheme` styles (`titleLarge`, `labelMedium`, `titleSmall`, `bodyLarge`, `bodySmall`) via `Theme.of(context).textTheme`, not raw per-widget `fontSize` values below 12 (REQ-F04-021).
