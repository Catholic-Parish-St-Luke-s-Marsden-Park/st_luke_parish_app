## Deviations From Reference Repo (intentional, in-scope)
- Sibling repo's `AppCard`/`PageHero`/`SectionHeader`/`PillButton` widgets were not copied wholesale; equivalent narrower-purpose widgets were written fresh (`ParishHeroBanner`, `SectionLabel`, `AboutStLukesSection`'s inline card, `AppPillButton`) using this repo's existing `AppColors`/`AppShapes`/`AppTypography` tokens, since the sibling repo's `AppColors` has an extra `cardHeaderGradient` token not present in this repo and out of scope to add here
- Sibling repo's separate "Parish Leadership" + "Diocese of Parramatta" cards were deliberately combined into the new single "Church Leadership" 3-part section per REQ-F02-004
- Added an injectable `UrlLauncherService` (via Riverpod provider) rather than calling `url_launcher`'s top-level functions directly from `LeadershipEntryTile`, so Tester phase can override `urlLauncherServiceProvider` with a fake/mock in widget tests without touching platform channels (this directly enables the "verifiable via a mocked/injected URL-launcher in widget tests" wording in REQ-F02-005)
- "Ask Luke" was built as its own feature module (`lib/features/ask_luke/`) rather than nested under Parish or inline in `app/shell/` — see `.claude/decisions/0001-ask-luke-own-feature-module.md`
- `AppPillButton` was made deliberately compact (small font/padding) to reduce AppBar width pressure now that the per-tab text title is gone and 5 elements (hamburger, logo, 2 pills) must fit in one row — a mitigation for the width-pressure risk the BA plan flagged, not a scope change
