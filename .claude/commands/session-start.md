# Command: session-start

## Steps
1. Read root `CLAUDE.md`
2. Read `.claude/memory.md`
3. Read the active feature row in `.claude/context/feature-index.md`
4. Read the latest relevant plan, journal, and verification report
5. Confirm current branch, feature, and phase
6. Ask clarifying questions if anything is unclear

See `.claude/hooks/before-phase.md` for the checklist to confirm before resuming work in the active phase.
